# DNSutils++

A container with dns tools like: nslookup and dig in addition to various other diagnostic tools. Inspired by the now retired jessie-dnsutils from <https://github.com/kubernetes/kubernetes/>

## Software included

- curl
- dig
- hey
- host
- jq
- netcat
- nmap
- nslookup
- openssl
- traceroute
- watch
- wget
- yq
